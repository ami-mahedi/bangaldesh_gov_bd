# 🇧🇩 Old Bangladesh Project

### A Journey Through the Previous Design of Bangladesh National Portal

## 📌 Project Overview

Old Bangladesh Project is a frontend recreation of the previous design of the Bangladesh National Portal. This project represents an effort to recreate the older website layout and user interface using fundamental frontend web technologies.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript

## ✨ Key Features

- Old Bangladesh National Portal-inspired design
- Structured webpage layout
- Navigation and content sections
- Responsive styling where implemented
- Interactive elements using JavaScript where implemented
- Clean and organized frontend code

## 🎯 Project Objectives

- Practice frontend web development
- Improve HTML and CSS skills
- Understand Bootstrap-based layouts
- Develop practical JavaScript skills
- Recreate an existing website design for educational purposes
